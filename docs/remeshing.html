1_remeshing/Remeshing/

Put the MATLAB remeshing folder here: the folder that contains code/ (with the mex files) and remesh_batch.m. It is not part of this repository.

The remeshing scripts look for it here first, then in ~/Documents/MATLAB/Remeshing, so if it already lives there you can leave this folder empty. --remeshing-dir points them anywhere else.
