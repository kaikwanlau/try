02 / READ THE GEOMETRY

From surface to parameters.

Three complementary descriptors, illustrated with the same specimen. Select a step to see what it measures.

The fit starts from prepared, oriented meshes. Anatomical inspection remains essential. The ellipsoid semi-axes describe fitted geometry; they are not direct measurements of the brain.

03 / A FIRST RESULT YOU CAN INSPECT

Start small. Fit one skull.

The included example uses the existing orbital fitter. It exports a table, an inspection image and a record of the run.

A specimen is already included.

Download and extract the repository, install Python 3.12, then run these commands from its root folder. The example needs neither MATLAB nor an interactive 3D window.

It measures the orbit of G.DifficilisA.stl. Use the full workflow for the ellipsoid fit and larger batches.
